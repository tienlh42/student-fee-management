{% comment %} Gợi ý filter format tiền VNĐ (Django mặc định không có dấu chấm ngăn cách hàng nghìn kiểu VN — intcomma của django.contrib.humanize cho ra "4,600,000" chứ không phải "4.600.000"): # app/templatetags/vn_format.py from django import template register = template.Library() @register.filter def vnd(value): try: return f"{int(value):,}".replace(",", ".") + " đ" except (TypeError, ValueError): return "" Dùng trong view/serializer để tạo sẵn *_display trước khi đưa vào context, thay vì gọi filter ngay trong template — giữ template chỉ lo hiển thị, không lo format. {% endcomment %}
